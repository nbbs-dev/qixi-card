# Qixi Card

An interactive Three.js love card created for 七夕情人节.

## Live site

After GitHub Pages finishes the first deployment:

<https://nbbs-dev.github.io/qixi-card/>

## Local development

```bash
pnpm install
pnpm dev
```

## Deployment

Every push to `main` builds the Vite app and publishes `dist/client` through GitHub Actions.
